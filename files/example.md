# 欢迎使用 Markdown 文档库

这是一个示例 Markdown 文件，用于展示该系统的功能。

## 功能介绍

1. **文件列表主页**：展示所有可用的 Markdown 文件。
2. **直接打开文件**：通过 URL 参数 ?file=filename.md 直接访问。
3. **响应式设计**：支持在移动设备和桌面设备上浏览。

## 如何添加新文件

1. 将你的 .md 文件放入 iles 目录中。
2. 在根目录下的 iles.json 文件中添加该文件的名称。
3. 提交更改并推送到 GitHub。
