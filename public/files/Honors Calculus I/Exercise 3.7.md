We know that when $x \to +\infty$ , $\frac{2}{x} \to 0$.
So we know that its slant asymptote is $x > 0$ is:
$$y = x$$
so we have $m_{\text{asymptote}} = 1$, $m_{\text{tangent}} = -\frac{1}{m_{\text{asymptote}}} = -\frac{1}{1} = -1$

Then, we have:
$$y' = \frac{d}{dx}\left(x + \frac{2}{x}\right) = 1 - \frac{2}{x^2}$$
Make $y'=-1$:
$$1 - \frac{2}{x^2} = -1$$
$$x^2 = 1$$
We know that $x>0$,so: 
$$x = 1$$
Put it back to the source function:
$$y = 1 + \frac{2}{1} = 3$$
So we know that the tangent line goes through $(1,3)$.
So we have the function of the tangent line:
$$y - 3 = -1(x - 1)$$
$$y - 3 = -x + 1$$
$$y = -x + 4$$
So we've got the equation of the tangent line.
$Q.E.D.$
